# FinderActions v0.1.3

This patch release fixes the Finder context menu.

## Fixed

- FinderActions now appears in Finder's right-click menu.
- Added missing Finder extension metadata required by macOS.
- The Finder Sync extension now stays running and responds to menu requests.
- Menu actions continue to use the main app for file and clipboard operations.

## Install

1. Download the DMG or ZIP.
2. Move `FinderActions.app` to `/Applications`.
3. Enable the Finder extension in System Settings.
4. Restart Finder if needed.

## Important

This release is ad-hoc signed and is not Apple-notarized. macOS may show a security warning on first launch.
