# FinderActions v0.1.1

This release improves the background and menu bar experience.

## Added

- Menu bar mode
- Open Settings from the menu bar
- Toggle Launch at Login from the menu bar
- Quit FinderActions from the menu bar
- English / Chinese menu bar labels based on the selected language

## Changed

- Launching at login no longer opens the Settings window.
- Finder menu preferences are shared through a dedicated preferences suite.
- Menu presentation is now covered by focused tests.

## Install

1. Download the DMG or ZIP.
2. Move `FinderActions.app` to `/Applications`.
3. Enable the Finder extension in System Settings.
4. Restart Finder if needed.

## Important

This release is ad-hoc signed and is not Apple-notarized. macOS may show a security warning on first launch.

## Known limitations

- File Provider directories such as iCloud Drive, OneDrive, Dropbox, and Google Drive are unsupported.
- External drives and SMB shares are outside the v1 support scope.
