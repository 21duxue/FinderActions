# FinderActions v0.1.2

This patch release fixes the menu bar-only behavior.

## Fixed

- FinderActions no longer appears in the Dock when running in the background.
- The app now uses accessory activation policy and stays visible in the menu bar only.
- Opening Settings still works from the menu bar.

## Install

1. Download the DMG or ZIP.
2. Move `FinderActions.app` to `/Applications`.
3. Open FinderActions.
4. Enable the Finder extension in System Settings.
5. Restart Finder if needed.

## Important

This release is ad-hoc signed and is not Apple-notarized. macOS may show a security warning on first launch.
