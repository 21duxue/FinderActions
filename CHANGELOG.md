# Changelog

## v0.1.0

Initial public release.

### Included

- New File Here…
- Open Terminal Here
- Copy Path Here
- Copy Name Here
- Grouped and flat Finder menu modes
- Chinese / English interface
- Per-action enable switches
- Default file name setting
- Launch at login
- Finder extension status and settings shortcut
- App icon
- Core smoke tests

### Known limitations

- Not Apple-notarized.
- File Provider directories such as iCloud Drive and OneDrive are unsupported.
- External drives and SMB shares are unsupported.
