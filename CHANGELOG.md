# Changelog

## v0.1.0

Initial public release.

### Included

- New File Here…
- Open Terminal Here
- Copy Path Here
- Copy Name Here
- Grouped and flat Finder menu modes
- Chinese / English interface
- Per-action enable switches
- Default file name setting
- Menu bar app mode
- Launch at login
- Finder extension status and settings shortcut
- App icon
- Core smoke tests

### Known limitations

- Not Apple-notarized.
- File Provider directories such as iCloud Drive and OneDrive are unsupported.
- External drives and SMB shares are unsupported.

## v0.1.1

- Added menu bar mode.
- Login launch now runs in the menu bar without opening Settings.
- Added menu bar actions for opening Settings, toggling launch at login, and quitting.
- Improved Finder menu preference sharing.
- Added more unit and smoke tests.
